## The sign

> DO NOT BLOCK THE COLD AISLE. THE GHOST NEEDS THE AIRFLOW TO HOLD ITS SHAPE.

A facilities rule, taken seriously by a ghost: block the cold aisle and the
haunting loses its shape. Short, punchy, readable at a glance — the kind of
line taped to a server room door at 3am. The line is 75 characters, inside
the 120-character gate.

## How it runs

```sh
npm start
```

`main.ts` writes the single line above to `/output/entry.txt` (UTF-8, one line)
and nothing else. No dependencies, Node 22+.
